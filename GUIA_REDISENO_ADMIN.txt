CÓMO SUBIR A GITHUB
1. Haz una copia/descarga del repositorio actual antes de reemplazar archivos.
2. Descomprime este ZIP.
3. Copia los ARCHIVOS Y CARPETAS DE DENTRO al repositorio GitHub del ADMINISTRATIVO (NO al del POS).
4. Conserva los nombres de carpetas: src, public, package.json, index.html, etc.
5. Realiza Commit changes en la rama que despliega Vercel.
6. En Vercel comprueba Deployments -> Ready y revisa que el Inicio y las demás secciones abran.

No necesitas ejecutar scripts SQL ni agregar variables de entorno para el cambio visual.
No se han alterado tu Supabase ni tus datos de producción.
